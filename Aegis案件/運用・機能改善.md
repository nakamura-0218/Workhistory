# A1システム 閉域化対応 アウトプット
システム構成、機能、運用等の観点で改善した実績を以下に列挙。
以下実績は、Terraformによりコード管理

## VPC
- NAT Gatewayを1つから3つに変更し、各AZ用のroute tableを作成。デフォルトルートに各AZのNAT Gatewayを経由するルートを追加
- subnet / NAT Gateway / EIP / route table の命名規則を統一
- S3のゲートウェイ型VPCエンドポイントを追加し、private subnetのroute tableにルートを追加⇒ECSイメージpullなどのS3との通信量を無料に

## EC2
- 閉域化構成向けのセキュリティグループを新規作成

## ALB
- セキュリティポリシー（TLSバージョン・暗号スイート）をAWSが推奨している値に変更
- アクセスログ / コネクションログを有効化
- 削除保護を有効化

## S3
- バケットの命名規則を制定
- ALBログ格納用バケット作成とバケットポリシーの設定
- バケットのライフサイクル設定を変更

## Aurora
- 社内のローカル環境(DBツールpgadmin等)から、SSMポートフォワーディング経由でAuroraへ接続できる環境を構築
- prd Auroraのデータを毎晩dev Auroraへ同期するバッチ処理を追加


## 設計・ドキュメント
- SSHポートフォワーディングによる test DB 接続手順書を作成
