# A1システム 閉域化対応 アウトプット

## 1. 実績

### 1.1 設計・ドキュメント
- 閉域構成化の移行手順書を作成
- 閉域化構成のドメイン設計を策定
- AWS構成図を作成（閉域化前 / 閉域化後）
- Backlogチケットを起票し、タスクを管理

### 1.2 ALB のセキュリティ強化
- ALB セキュリティグループを Terraform で定義し、dev / prd 両環境へ適用
- ALB セキュリティポリシー（TLS バージョン・暗号スイート）を強化し、dev / prd 両環境へ適用
- ALB の削除保護を有効化

### 1.3 ALB ログ基盤の構築
- ログ格納用 S3 バケットの命名規則を制定
- ログ格納用 S3 バケットとバケットポリシーを Terraform で構築（dev / prd）
- ALB アクセスログ / コネクションログを有効化
- S3 バケットのライフサイクル設定を変更

### 1.4 VPCエンドポイント導入による通信の閉域化
- Terraform で VPCエンドポイントを定義し、dev / prd 両環境へ適用・動作確認
- AWSサービス向け通信をインターネット経由から VPCエンドポイント経由へ切り替え
- 不要なインターフェース型VPCエンドポイントを削除し、コストを削減

### 1.5 ネットワーク構成の再設計
- isolated subnet を追加した subnet 構成へ変更し、dev / prd 両環境へ適用
- NAT Gateway と route table のルート設定を修正し、prd 環境の疎通を復旧
- dev環境の VPC を新構成で再作成
- subnet / NAT Gateway / EIP / route table の命名規則を統一

### 1.6 DNS・証明書
- 閉域化構成向けのセキュリティグループを新規作成
- Route53 レコードを追加
- ACM 証明書を発行

### 1.7 IaC（Terraform）の整備
- Terraform 実行環境および Git 環境を構築
- Terraform コードのリファクタリング・定義形式の統一
- `terraform plan` のドリフトを解消
- プルリクエストのレビュー（#103 ほか複数）

### 1.8 データベース・検証環境の整備
- DB モニタリング設定を修正し prd 環境へ適用
- 社用PCから SSH ポートフォワーディング経由で test DB へ接続できる環境を整備
- 上記接続手順のドキュメントを作成
- test環境の Web ポータルサイト構成を構築
